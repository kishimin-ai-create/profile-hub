# Report Output

Always output the following when work ends.

## Mutation Statistics

```text
Total Mutants:
Killed:
Survived:
Equivalent:
Not Covered:
Timeout:
Invalid:
Raw Mutation Score:
Effective Mutation Score:
```

## Initial Result

```text
Initial Mutation Score:
Initial Actionable Survived:
```

## Final Result

```text
Final Mutation Score:
Final Actionable Survived:
```

## Added Test Cases

Record the following for every test:

```text
Test:
Target Mutant:
Mutation Type:
Missing Behavior:
Added Case:
Result:
```

## Remaining Mutants

List every remaining mutant:

```text
Mutant ID:
File:
Line:
Mutation:
Classification:
Reason:
Evidence:
```

Explicitly state when zero mutants remain.

---

# Completion Conditions

Do not complete the work until every condition is satisfied:

```text
Normal tests pass
Mutation Test rerun completed
Actionable Survived = 0
Unclassified Mutants = 0
Not Covered = 0
Uninvestigated Timeouts = 0
Equivalent Mutant rationale recorded
Relationship between added tests and target Mutants recorded
Effective Mutation Score = 100%
```

Do not report completion if even one condition is unsatisfied. Explicitly report `Incomplete` and list the remaining work.

---

# Final Principles

Do not pursue a score as the purpose of Mutation Testing. Question the test code itself.

Do not trust the fact that tests passed. Do not trust 100% coverage. Do not trust tests generated by AI.

Deliberately break production code and confirm that tests detect the error.

**A surviving mutant is a question from the test suite.**

Do not ignore that question. Continue investigating until the mutant is killed or proven equivalent.
